# Chan zone · 禅意番茄钟

> *需要的不多，想要的太多。*  
> — 圣严法师 · 108自在语

一款为**深度专注**设计的 macOS 浮动计时器。不是又一个番茄钟 app——它是一个仪式感工具，帮你在每次开始工作前，先完成一次微小的心理切换。

---

## 为什么做这个

现代效率工具普遍误解了"专注"：更多通知、更多数据、更多提醒。  
真正的专注不需要被管理，它需要被**进入**。

Chan zone 来自上海大学雲水讀書社的内部工具实验。我们希望用禅宗的简朴美学，做一个能让人**安静下来**的计时器：  
- 开始时，三声木鱼声，像翻开书前的深呼吸  
- 结束时，一声引磬，像课结束后的回向  
- 中间，只有时间流逝

---

## 功能

**核心体验**
- 浮动透明窗口，`always-on-top`，不干扰主工作区
- 三种模式：专注 / 小憩 / 长休，自动轮换记录轮次
- 木鱼声（开始 · 三响）+ 引磬声（结束 · 一响）
- 菜单栏实时倒计时，合上窗口也不会错过

**设计细节**
- 极简模式（compact）：一键切换为 280×360 迷你窗口
- 禅宗毛笔圆（ensō）进度环，不是普通的进度条
- 圣严法师语录随机轮换，每轮结束换一句
- 暂停时立即中断木鱼序列，不留声音残留

**效率集成**
- 完成后一键写入 **苹果日历**（.ics 方案，无需授权弹窗）
- 中途暂停可手动记录已用时段
- 设置页可直接试听木鱼 / 引磬音效

## 安装

**运行源码（需 Node.js）**

```bash
git clone https://github.com/Tree-rock/Chan-zone.git
cd Chan-zone
npm install
npm start
```

**本地构建 .app（macOS arm64）**

```bash
npm run build
# 产物在 dist/mac-arm64/Chan zone.app
```

> 未签名 app，首次打开需在「系统设置 → 隐私与安全」点击「仍要打开」

## 技术栈

| 层 | 技术 |
|---|---|
| 框架 | Electron 32 |
| 渲染 | 原生 HTML / CSS / JS，无前端框架 |
| 音频 | HTMLAudioElement（无 AudioContext 状态问题）|
| 日历 | RFC 5545 `.ics` + `shell.openPath`（绕过 TCC 权限）|
| 图标 | 上大雲水讀書社社标 · 行舟人，`iconutil` 打包 |
| 构建 | electron-builder，target: dir，arm64 |

---

## 设计原则

1. **仪式大于功能** — 木鱼声不是通知，是开始工作的仪式
2. **减法优先** — 没有统计图表、没有成就系统、没有账号
3. **不打扰主界面** — 浮动窗口、透明背景、可随时隐藏
4. **声音是空间的一部分** — 引磬声在 5 秒内自然消散，不占用注意力
